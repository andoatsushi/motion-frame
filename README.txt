Motion Frame v1.0 — マンガ用 2.5D動画編集アプリ
============================================

■ どんなアプリ？
漫画の背景・人物・前景などの画像を別レイヤーとして配置し、
移動・ズーム・回転・透明度・カメラ移動・奥行き表現をつけて、
数秒の短い動画にするブラウザアプリの試作版です。

このバージョンはHTML 1ファイルだけで動きます。編集データは
基本的にブラウザ内で処理します（外部のAIサービスのリンクを
自分で開いた場合を除き、素材をサーバーに送信しません）。

■ 最初に試す手順
1. index.html をSafariやPCのブラウザで開く。
   iPhone/iPadでは下記のGitHub Pages公開をおすすめします。
2. 右上の「サンプル」を押す。3枚のレイヤーが読み込まれます。
3. 中央下の「▶ 再生」で、4秒間の2.5Dアニメーションを確認。
4. 左側のレイヤーを選び、右側の「開始」「終了」で各数値を編集。
5. 「カメラ」モードに切り替え、画面全体の動きを設定。
6. 「AI / 出力」モードで、動画かPNG連番ZIPを書き出し。
7. 編集の途中では、右上の「プロジェクト保存」を押してZIP保存。

■ 自分の漫画を使うとき
- 「＋画像」からPNG / JPEG / WebPなどを読み込みます。
- なるべく背景・人物・前景を透明PNGに分けてください。
- 「＋動画」からAIで生成済みのMP4/WebM/MOVを読み込めます。
  動画形式が再生できるかはブラウザの対応コーデックに依存します。
- 画像の背景消去や人物のパーツ分離は本アプリでは自動実行しません。
- 選択レイヤーをプレビューでドラッグして位置調整できます。
- 開始と終了で別の値を設定すると、その間を滑らかに補間します。
- カメラとレイヤーの「奥行き」を組み合わせるとパララックスが生じます。

■ 動画生成AIについて（初期版の制限）
Kling / Vidu / HailuoなどのAPIへ直接接続する機能は未実装です。
AI / 出力画面で指示文を作成・コピーして公式サイトで生成し、
できた動画を本アプリに読み込んで合成してください。

将来AIのAPI接続を追加する場合、APIキーをこのHTMLへ直書きせず、
Cloudflare Workers等のサーバー側で保管する構成が必要です。

■ 書き出しと対応ブラウザについて
- 動画: MediaRecorderとcanvas.captureStreamをブラウザがサポート
  する場合に、対応するMP4またはWebMで録画します。
- PNG連番ZIP: 動画録画に対応しないブラウザの代替方法です。
- 現在のフレームPNG: 静止画の書き出しができます。
- 音声は読み込み・書き出しの対象外です。
- デスクトップChromiumではMP4/H.264、PNG連番ZIP、ZIPの
  保存・再読込をテストしました。
- iPad/iPhoneのSafari実機での書き出し動作は未検証です。
  うまく動画出力できない場合はPNG連番ZIPを使ってください。
- 1080幅や24fpsでの連番書き出しはファイルが大きくなり、
  iPhone/iPadのメモリを大量に消費します。最初は540幅/12fps推奨。

■ GitHub Pagesで公開する方法
1. ZIP内の index.html を取り出す。
2. GitHubで新しいリポジトリを作る（または既存リポジトリを使用）。
3. index.html をリポジトリ直下にアップロード・コミットする。
4. Settings → Pages → Build and deployment の Source で
   Deploy from a branch を選び、main / (root) を指定して保存。
5. 発行されるGitHub PagesのURLをSafariで開く。
6. Safariの共有メニューから「ホーム画面に追加」しても使えます。

■ プロジェクトのバックアップ
「プロジェクト保存」すると、すべての画像・動画素材と編集設定を
含んだZIPが出力されます。「読込」でそのZIPを復元できます。
アプリ自体には自動クラウド保存・アカウント同期機能はありません。
